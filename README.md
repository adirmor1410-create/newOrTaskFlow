# גירה מדור אור 📋

מערכת מתקדמת לניהול משימות, פרויקטים וצוותים (Kanban & Gantt) עם תמיכה מלאה בעברית (RTL), התאמה אישית, מעקב גרסאות ואחסון מקומי מבוסס SQLite.

---

## ✨ תכונות עיקריות

- **לוחות קנבן מתקדמים (Kanban Boards)**:
  - 6 שלבים קנוניים מובנים: *לביצוע*, *בדיקות קוואס*, *בדיקות שילובים*, *הושלם*, *תקלה*, *בוטל*.
  - גרירה ושחרור (Drag & Drop) של משימות ועמודות.
  - סינון משימות לפי חברי צוות, תוויות, שמות תצוגה ומשימות שלי.
- **תרשים גאנט מדויק (Gantt Chart)**:
  - דיוק קלנדרי מלא לפי תאריכים יומיים (`Date.UTC`), גלילה שוטפת, כפתור "קפיצה להיום" (Jump to Today) ורמת זום מתכווננת.
- **ניהול צוותים ופרויקטים (Teams & Projects)**:
  - תמיכה במספר צוותים ופרויקטים במקביל.
  - מסך תרשימים ודשבורד כלל ארגוני.
- **ניהול גרסאות ויעדים (Milestones & Releases)**:
  - שיוך משימות לגרסאות יעד (Target Versions) ומעקב זמנים.
- **קבצים, מסמכים ומדיה**:
  - העלאה והורדה של קבצים ומסמכים מצורפים לפרויקטים ומשימות.
  - צירוף תמונות ומדיה ישירות בתגובות למשימות.
- **אחסון נתונים אמין ב-SQLite**:
  - אחסון מקומי בקובץ `.db` לפי נתיב מוגדר במשתני סביבה.
  - פתיחה וסגירה מיידית לפי דרישה בכל קריאה וכתיבה ללא נעילת קבצים קבועה.
- **זיהוי משתמשים והרשאות**:
  - זיהוי אוטומטי לפי שם המשתמש במחשב (OS Computer Username).
  - הרשאות מנהל מערכת (Admin) מוגדרות דרך משתני סביבה (`VITE_ADMIN_USERNAME`).

---

## 🚀 התקנה והרצה

### 1. דרישות קדם
- [Node.js](https://nodejs.org/) גרסה 18 ומעלה.

### 2. התקנת תלויות
```bash
npm install
```

### 3. הגדרת משתני סביבה
העתק את קובץ הדוגמה `.env.example` לקובץ `.env`:
```bash
cp .env.example .env
```
ערוך את קובץ `.env` לפי הצורך:
```ini
# שם משתמש המחשב של מנהל המערכת (Admin)
VITE_ADMIN_USERNAME=adir7

# נתיב קובץ מסד הנתונים SQLite
TASKBOARD_DATA_PATH=./taskboard.db
```

### 4. הפעלת שרת הפיתוח
```bash
npm run dev
```
או להפעיל באמצעות הסקריפט:
```cmd
start-taskboard.bat
```
לאחר מכן פתח בדפדפן את הכתובת: [http://127.0.0.1:5173/](http://127.0.0.1:5173/)

### 5. בנייה לייצור (Build)
```bash
npm run build
```
התוצרים יישמרו בתיקיית `dist/`.
